# Multilayer Perceptron — Breast Cancer Classification

A neural network built from scratch in Python, trained to classify breast cancer tumors as **Malignant (M)** or **Benign (B)** using the Wisconsin Breast Cancer dataset.

No neural network library is used — only NumPy for linear algebra and Matplotlib for visualization.

---

## Architecture

```
Input (30 features)
    │
    ▼
Dense(30 → 10) + ReLU
    │
    ▼
Dense(10 → 24) + ReLU
    │
    ▼
Dense(24 → 8)  + ReLU
    │
    ▼
Dense(8  → 2)  + Softmax   ← training  (CCE loss)
                 Sigmoid    ← inference (BCE loss)
```

The default architecture uses **3 hidden layers**. It is fully configurable via `--layer`.

### 2. Train

Pass the raw dataset directly — it is automatically split into train/validation sets:

```bash
python3 main.py data.csv
```

Runs backpropagation + gradient descent over epochs. Saves weights to `export.json`.

You can also pass pre-split files if needed:

```bash
python3 main.py train_set.csv validation_set.csv
```

**Available options:**

| Argument | Default | Description |
|----------|---------|-------------|
| `--split` | 0.2 | Validation ratio for auto-split |
| `--epochs` | 70 | Number of training epochs |
| `--batch_size` | 16 | Samples per gradient update |
| `--learning_rate` | 0.01 | Step size for weight updates |
| `--layer N [N ...]` | `10 24 8` | Hidden layer sizes |
| `--patience` | 3 | Early stopping patience |
| `--adam` | off | Use Adam optimizer instead of SGD |

## How It Works

### Forward Propagation

Input data flows through each layer:

```
output = activation(input @ W + b)
```

Each layer stores its input for the backward pass.

### Backpropagation

Gradients are computed using the chain rule from the loss backward through each layer:

- **Last layer (fused gradient):** for Softmax+CCE or Sigmoid+BCE, the delta simplifies to `(ŷ - y) / batch_size`
- **Hidden layers:** `δ_prev = δ @ W.T`, then `dW = input.T @ δ`, `db = sum(δ, axis=0)`

### Weight Update

```
W = W - lr * dW
b = b - lr * db
```

With **Adam**, gradients are scaled by their running mean and variance with bias correction.

### Early Stopping

Training stops automatically when validation loss stops improving for `--patience` consecutive epochs, preventing overfitting.
